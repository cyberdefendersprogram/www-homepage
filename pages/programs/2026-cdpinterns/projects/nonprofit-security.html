2026 Summer Cohort — Capstone Project

Secure the Mission: Nonprofit Security Assessment Lab

Sponsored by AllWomenCount

Project Brief

Security Assessment for a Community Organization

This track connects an intern with a community nonprofit to provide practical security support alongside a structured risk assessment — real systems, real staff, real constraints, and outcomes the organization can act on immediately. Work spanned improving day-to-day technical reliability, assessing AllWomenCount's cybersecurity posture, and leaving behind clear, prioritized recommendations that non-technical staff can follow. Findings also benefited the SF Living Wage Coalition.

Capstone Team

  • Amal Saleh — Merritt College · Completed

Project Workstreams

Cybersecurity Assessment

Reviewed current devices and workflows, identified vulnerabilities, and produced a prioritized list of recommendations the organization can realistically implement.

Security Improvements

Worked on password practices, account protection, secure data handling, and basic endpoint security — focusing on changes with the highest practical impact.

Privacy & Data Protection

Reviewed data flows for programs and donors, and recommended improvements to protect sensitive information with simple privacy practices staff can sustain independently.

Deliverables

Security Assessment Report Final Presentation

Track Scope: Expected Outcomes

  • Improved reliability of computers and systems for the organization's daily work.
  • A professional security risk assessment report suitable for stakeholders, grant conversations, and partner discussions.
  • Clear, prioritized security recommendations written for non-technical staff.
  • Lightweight documentation for recurring technical problems.
  • Increased staff confidence in handling basic tech issues independently.
